# 杭州出发 · 2026 中秋国庆假期机票价格报告

单文件纯静态报告：`index.html` 内含全部样式与逻辑，数据、图表引擎、字体、地图边界均为同目录本地文件，
不含任何外部 URL。双击 `file://` 打开即可完整渲染，内网/离线环境可直接托管（部署细节见 [DEPLOY.md](DEPLOY.md)）。

报告覆盖「出发日 × 返程日」价格矩阵、假期日历、走势曲线、地图可达性与全量城市价格表。

## 数据口径

**口径** 价格为「去程该日单程最低价 + 返程该日单程最低价」的**理论组合**，含基建燃油，可能跨承运人，
不保证能作为一张往返票按此总价购买。飞猪另有同商家可售往返打包价（`data/flight-mtop.js`），通常高出 5–24%，
两者不可混比。同城多机场在展示层合并为一个城市、取最低价。无报价即留空，不以邻日价格顶替。

**统计** 全报告中位数与按色深浅分级处，口径统一为**截尾**：先剔掉一个最高、一个最低（样本 ≤3 不裁）
再统计或等分色带，免得个别极端值独占一档、把中间差异糊成同色；被剔的极值仍照常画出，只贴两端色档。

**来源** 飞猪 mtop `getCheapestPriceCalendar` v3.0，浏览器会话实时取数；候选集为 OpenFlights 公开机场库中
全部中国民航 IATA 码（有效码数与城市数见页眉，均由数据实算）。接口返回 0 或缺条目即记为无报价，不做推算。
机场码 `PEK/XIY/PVG` 返回 0 而城市码 `BJS/SIA/SHA` 有价者，已按城市码补查。

**配色校验** 结构色为主色深蓝 60%、灰白 30%、强调橙 10%。多序列折线取已验证色板前 5 槽
（色盲相邻分离 ≥8、正常视觉 ≥15）。价格色带六档明度单调、最浅档对白底 1.59:1，
「无报价」另用近空白灰加虚线描边，避免与最低价档混淆。
